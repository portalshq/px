# px_auth_login
Sign in through the configured Lore authentication service


## Parameters

| Name | Type | Required | Default | Description |
|---|---|---|---|---|
| api\_key | boolean | No | false | Exchange a service-account API key instead of opening a browser |
| api\_key\_env | string | No | PORTALS\_CLOUD\_API\_KEY | Environment variable containing the API key |
| no\_browser | boolean | No | false | Print the login URL without opening a browser |
