06 / the developer surface

Install it.
Make something.

px ships with an MCP server, agent skills, and a command line tool for resolving and editing resources inside your project.

1. Install PX + skills

curl -fsSL https://github.com/portalshq/px/releases/latest/download/install.sh | bash && npx skills add portalshq/px

2. Initialize a repository

# Initialize a new repository
px init eye-candy

# Initialize with local provider
px init eye-candy --provider local

# Initialize with remote provider
px init --provider remote --remote-url lore://127.0.0.1:41337 --workspace-id my-workspace

# Configure provider only (no repository creation)
px init --provider local

# Initialize with a remote origin
px init eye-candy --origin lore://127.0.0.1:41337/eye-candy

3. Create an entity

# Create a character
px create character dua -u eye-candy -n "Dua"

# Create a location
px create location underground-station -u eye-candy -n "Underground Station"

px create character dua -u eye-candy -n "Dua"

4. Add a representation

# Save a generated scene clip as a video representation
px add px://eye-candy/scene/dua-orbit-station clip-01 ./dua-orbit-station-clip-01.mp4 --format mp4 -m "Add dua-orbit-station scene clip"

# Save another take under a distinct representation key
px add px://eye-candy/scene/dua-orbit-station clip-02 ./dua-orbit-station-clip-02.mp4 --format mp4 -m "Add alternate dua-orbit-station scene clip"

# Inspect the scene and direct representation provenance
px resolve px://eye-candy/scene/dua-orbit-station --provenance

import { presignRepresentation } from "@portalshq/px";

const result = await presignRepresentation(

  "character_sheet",
  { branch: "episode-1", ttlSeconds: 900 },
);

from px_sdk import presign_representation

result = presign_representation(

)
